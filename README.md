# ReStakeX BTC

ReStakeX BTC is a Bitcoin-native restaking protocol built on OPNet.

## Overview

ReStakeX BTC enables users to restake BTC-backed assets in order to secure additional decentralized services and earn layered yield.

The protocol introduces shared security and capital efficiency mechanisms to the Bitcoin ecosystem.

## Core Features

- Bitcoin-based restaking
- Liquid Restaking Token (rxBTC)
- Modular validator support
- Yield distribution logic

## Architecture

User → Restake Module → Validator Layer → Reward Engine
